# Résumé de cours : L'IA et l'IA Générative

## 1. Hiérarchie des concepts
* **IA (Intelligence Artificielle) :** Domaine global simulant l'intelligence humaine.
* **ML (Machine Learning) :** Apprentissage automatique basé sur la classification et la prédiction.
* **DL (Deep Learning) :** Apprentissage profond s'appuyant sur les réseaux de neurones.
* **LLM (Large Language Models) :** Modèles de langage créateurs de contenu (texte, vidéo, audio).

## 2. Fonctionnement probabiliste
Les LLM génèrent le contenu mot par mot (token par token) en calculant les probabilités des mots suivants à partir du contexte.

## 3. Limites de l'IA
1. **Hallucinations :** Génération d'informations crédibles mais factuellement fausses.
2. **Biais :** Reproductions de préjugés contenus dans les données d'entraînement.
