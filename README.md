1. C’est quoi l’intelligence artificielle ?
L’intelligence artificielle est une technologie qui permet aux machines de réaliser des tâches qui demandent normalement l’intelligence humaine, comme comprendre une question, apprendre, résoudre un problème ou reconnaître une image.
Par exemple, ChatGPT utilise l’IA pour répondre aux questions et expliquer des cours.

2. Les différents types d’IA
Il faut comprendre que l’IA est le domaine général et que le Machine Learning et le Deep Learning sont des parties de ce domaine.

IA (Intelligence artificielle) : c’est le domaine général.
ML (Machine Learning) : la machine apprend à partir des données pour faire des prédictions ou des classifications. Par exemple, reconnaître les courriers indésirables dans une boîte mail.
DL (Deep Learning) : c’est une méthode du Machine Learning qui utilise des réseaux de neurones à plusieurs couches. Par exemple, reconnaître un visage sur une photo.
LLM (Large Language Model) : c’est un grand modèle de langage qui permet de comprendre et de générer du texte, comme ChatGPT.

3. L’IA générative
L’IA générative est une IA capable de créer de nouveaux contenus à partir d’une demande de l’utilisateur.
Par exemple, elle peut écrire un texte, résumer un cours, créer une image ou générer du code informatique.
La différence avec un simple moteur de recherche, c’est qu’elle peut produire un nouveau contenu au lieu de seulement rechercher des informations déjà existantes.

4. Comment fonctionne un LLM ?
Un LLM apprend à partir d'une grande quantité de données textuelles. Ensuite, il utilise ce qu’il a appris et le contexte de la question pour générer une réponse.Mais,une réponse bien écrite n’est pas forcément une réponse correcte. Le modèle peut faire des erreurs ou donner de fausses informations.

5. Le prompt
Un prompt, c’est simplement la consigne ou la question qu’on donne à l’IA.Par exemple :
Prompt: « Explique python. »
prompt: « Explique python à un étudiant de première année LT en 200 mots dans un tableau. »
Le deuxième prompt est meilleur parce qu’il précise ce qu’on veut,à qui s’adresse l’explication et quelle longueur on souhaite.

6. Les hallucinations de l’IA
Une hallucination se produit lorsque l’IA donne une information fausse ou inventée, mais qui semble vraie.
Par exemple, elle peut inventer le titre d’un article scientifique ou donner un faux nom d’auteur,c’est pourquoi il ne faut pas croire automatiquement tout ce que l’IA dit.

7. Comment vérifier une référence scientifique ?
Quand l’IA donne une référence scientifique, il faut vérifier si elle existe réellement.

Pour cela, on vérifie :
Le titre de l’article,les noms des auteurs,le nom de la revue scientifique,l’année de publication.
Il faut utiliser une source fiable pour faire cette vérification.

8. Les biais de l’IA
Un biais, c’est lorsqu’une IA donne des résultats injustes ou moins précis pour certaines personnes ou certains groupes.
Par exemple, si une IA est entraînée principalement avec des photos de personnes d’un groupe, elle peut être moins performante pour reconnaître les personnes d’un autre groupe.
